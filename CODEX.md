# Codex Notes

This repository is a small GNOME Shell extension named Window Navigator. It lets
users move focus between windows using directional hotkeys.

## Key Commands

- Build (TypeScript compile): `make`
- Package extension: `make pack`
- Install locally: `make install`
- Run tests: `make test`
- Clean build outputs: `make clean`

## Developer Notes

- The project follows GNOME extension docs and uses `make` for the main workflow.
